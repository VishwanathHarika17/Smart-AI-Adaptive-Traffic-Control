# Smart AI Adaptive Traffic Control System

## 1. Project Overview

The **Smart AI Adaptive Traffic Control System** is a data-driven traffic monitoring and analytics project designed to analyze traffic conditions across different areas of Bengaluru.

The project uses historical traffic data to identify congestion patterns, analyze traffic volume, monitor average vehicle speed, and provide meaningful insights through Python-based visualizations and an interactive Power BI dashboard.

## 2. Problem Statement

Traffic congestion is a major challenge in urban areas like Bengaluru. Traffic conditions vary depending on the location, time of day, traffic volume, road capacity, and other factors.

This project aims to analyze traffic data and present useful insights that can support better traffic monitoring and traffic management decisions.

## 3. Project Objectives

- Analyze historical traffic data.
- Identify high, medium, and low traffic conditions.
- Analyze area-wise traffic volume.
- Study average vehicle speed and congestion patterns.
- Visualize traffic trends over time.
- Develop an interactive Power BI dashboard.
- Support data-driven traffic management decisions.
