# Data Collection

## 1. Project Name
Smart AI Adaptive Traffic Control System

## 2. Dataset Name
Bangalore Traffic Timely Dataset

## 3. Dataset Source

Platform: Kaggle

Dataset Title: Bangalore Traffic 2023-2024

Dataset URL: https://www.kaggle.com/datasets/sandheepkochi/bangalore-traffic-2023-2024

Dataset Contributor: sandheepkochi


## 4. Purpose of Data Collection
The dataset is used to study traffic conditions
and understand traffic patterns in Bangalore.

It supports the analysis of traffic volume,
average speed, congestion levels, and other
traffic-related factors.

## 5. Dataset Files
- bangalore_traffic_timely_data.csv
  - Original traffic dataset
- bangalore_traffic_cleaned.csv
  - Cleaned dataset used for analysis

## 6. Important Attributes
- Date
- Area Name
- Road/Intersection Name
- Traffic Volume
- Average Speed
- Travel Time Index
- Congestion Level
- Road Capacity Utilization
- Incident Reports
- Weather Conditions
- TimeBlock

## 7. Data Preparation
The original dataset is processed using
data_cleaning.py.

The cleaned dataset is saved as
bangalore_traffic_cleaned.csv.

## 8. Limitations
The analysis depends on the quality and
completeness of the collected dataset.
